Workflows

Two n8n workflows I run for my own business.

Before I build anything for a client, I run it on Clear Path Digital first. These two handle my cold outreach and my LinkedIn posting. Both are live, and both have limits I set on purpose.

Mon–Fri, 9:00 AM

Cold outreach and follow-ups

I keep my leads in a Google Sheet. Every morning this workflow reads it, works out where each lead is (first email, 3-day follow-up, or 5-day break-up) and writes an email based on the audit I did of that lead's business. It sends from my Gmail and updates the sheet.

Schedule→Google Sheets→Stage check (JS)→Gemini 2.5 Flash→Gmail→Sheet update
Why it's built this way: it skips anyone who declined, bounced or already booked. It sends 25 emails a day at most, with a 30-second wait between each, so my domain doesn't look like a spam cannon. The AI writes the body only. The greeting and signature are added by code, so they're always right.
Mon / Wed / Fri, 9:00 AM

LinkedIn post generator

Picks a topic and a post format, writes the post, draws a flow diagram to go with it, and queues it in Buffer for the Clear Path Digital page. Every post gets logged so the next run knows what I already covered.

Schedule→Post log (Sheets)→Topic picker (JS)→OpenAI→Mermaid diagram→Buffer→Log
Why it's built this way: my early posts all used the same hook, so I split topic and format into separate choices. The picker avoids the last 10 topics and last 3 formats, and gives more weight to topics that did well for me on LinkedIn. The diagram is generated from the same run, so it matches the post.
